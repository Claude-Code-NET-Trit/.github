# Curso Claude Code .NET · TrainingIT

Material del curso **[Claude Code .NET: programa con IA desde la terminal](https://www.trainingit.es/producto/claude-code-net/)** de TrainingIT.

Aquí tienes un repositorio por cada tema del curso, con las diapositivas, el código y una guía de cada vídeo. Los temas teóricos incluyen las diapositivas, y los prácticos, el código del proyecto con el que trabajamos.

## Por dónde empezar

Empieza por el tema 1, donde se instala todo lo necesario. En el tema 2 descargarás el proyecto .NET con el que trabajarás el resto del curso. Cada repositorio tiene su propia guía con lo que contiene y cómo usarlo.
